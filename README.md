# 不落桌宠 · Codex 适配版

一只陪着你使用 Codex 的透明桌宠：待机、思考、书写、走路、拖拽，也可以按需开启碎碎念。附带“不落”角色的 **24 段动画成品**，大小、位置、名字和动作可以在插件设置里调整。

基于 **[PC2005-cloud/dsh-pet](https://github.com/PC2005-cloud/dsh-pet)** 的桌宠运行核心，由 **blue122311 与不落**适配和维护。感谢原作者开放源码。来源与许可见 [ATTRIBUTION.md](ATTRIBUTION.md) 和 [LICENSE](LICENSE)。

## 三步安装

适用于 **Windows x64 和普通 Codex 桌面版**，版本 **0.3.0**。完整包已带运行环境和构建成品，不需要另装 Node.js、npm、Python 或其他本地宿主。

1. 下载 [buluo-pet-codex-0.3.0-windows-x64.zip](https://github.com/blue122311/buluo-pet-codex/releases/download/v0.3.0/buluo-pet-codex-0.3.0-windows-x64.zip)，**先完整解压**。
2. 双击解压目录中的 **`安装-不落桌宠.cmd`**，等待安装完成。
3. **完整退出并重新打开 Codex**，在插件设置中找到“不落桌宠”，控制显示、位置和动作。

也可以从 [v0.3.0 下载页](https://github.com/blue122311/buluo-pet-codex/releases/tag/v0.3.0) 选择完整包。直接使用请认准文件名中的 **`windows-x64`**；`source-code-0.3.0.zip` 是供阅读和研究的源码归档。

安装器默认将文件放在 `%LOCALAPPDATA%\BuluoPetCodex`，通过 Codex 官方插件命令注册本地插件来源并安装插件。升级会备份旧安装，保留已有记忆和设置。它不会自行重启 Codex、安装常驻服务、添加 Hook 或修改调试端口。

## 功能与读取范围

**基本桌宠功能不调用模型。** 动画、拖拽、设置和任务状态联动可以独立使用。状态来自本机保存的 Codex 会话日志，聚合主会话活动，不能保证与当前前台聊天完全一致；未保存或仅在云端的会话不在读取范围内，日志尚未写入时也会有延迟。

**碎碎念和对话上下文默认关闭。** 开启碎碎念后，才会只读复用你自己的 Codex 登录来请求模型，不刷新或改写登录凭据。当前使用 `gpt-6-luna`、`max` 推理强度，能否实际调用以你的账号和服务端当时的支持为准。

开启对话上下文后，插件在本机读取普通 Codex 的会话索引和日志，最多取最近 12 条对话、累计 8000 字，用于碎碎念生成。不读取正式记忆库，也不需要 Python。可以在插件设置中选择聊天来源和主会话；关闭上下文时，不读取这些对话作为生成资料。

## 包内内容

完整 Windows 包包含 Node.js **24.21.0**、Electron **43.3.0**、已构建的桌宠运行代码和 24 段“不落”动画。运行时的原许可证随包保留。

本次不附带上游默认 106 段动画、上首软糖体字体或上游表情包，文字显示使用系统字体回退。“不落”角色与动画此次仅作公开分享，未另行授予素材许可证；代码的 MIT 许可不自动适用于这些原创素材。

已在隔离的 Codex 配置与安装目录中完成官方 CLI 注册安装、插件设置读取、渲染进程启动和合成任务状态联动检查；未做另一台电脑的完整画面验收。
